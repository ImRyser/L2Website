Our Tools

Grok

Grok is a coding website that teaches and develops your coding skills to an advanced level. This website is useful as it can teach users different coding languages.

Vs Code

Vs Code is a sandbox coding app that allows users to create anything they want by using coding languages.

Scratch

Scratch is a free coding website and online community that allows users to code games and publish them for other users to see, this is a very simple coding platform that teaches users the basics of how to code.

Code.org

Code.org is a coding website that is similar to grok, it teaches users how to code and improves their coding skills to a much higher level. This website is great because it teaches different coding languages based on year groups which helps younger users learn easier coding languages as they would understand that type of coding language better.

W3schools

W3schools is an informative website that provides users with examples and tutorials for multiple advanced coding languages. (e.g. HTML, CSS, Javascript, Python, SQL)

Website is free and is best used for any experience level
