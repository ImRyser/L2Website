Our Tools

Grok

Grok is an online learning platform that teaches and develops users programming/coding skills. It provides interactive courses and activites that help users learn how to code in a fun and practical way. Grok offers lessons on programming languages such as Python, HTML, and CSS with students using these languages to complete different challenges and problems.

Visual Studio Code

Visual Studio Code, sometimes reffered to as VS Code is a free sandbox coding app developed by Microsoft, It is used by programmers to create basically anything and supports many programming languages such as Python, JavaScript, HTML, and CSS. Visual Studio Code can also be customized using extensions which helps VS Code to support more coding languages, themes, debugging tools, and many other useful features which makes Visual Studio Code suitable for beginners aswell as experienced coders.

Scratch

Scratch is a free online coding website designed to help users learn the very basics of coding and is especially popular with beginners since instead of typing lots of complicated codes, you instead use colourful blocks that can be dragged and connected together, with each block giving the computer an instruction, such as moving a character, playing a sound, changing the background, or repeating an action. This makes programming easier to understand.

Code.org

Code.org is an online educational platform that helps users learn how to program/code. It is mainly designed for students and teachers and provides interactive lessons, activites, and coding challenges. Code.org teaches programming through different types of activites, for example beginners can use block based coding (similar to Scratch) where they drag and connect blocks to complete coding activites, while more advanced coders can use programming languages such as JavaScript, Python, HTML, and CSS to complete coding challenges.

W3Schools

W3Schools is an online learning website that helps people learn programming/coding, and web development. It provides tutorials, examples, exercises, and references for many different coding langauges. W3Schools covers many different coding languages such as HTML, CSS, JavaScript, Python, and SQL, which allows beginners to learn the basics and copy pieces of code straight from the website while experienced users can use the website as a reference when they need assistance with a particular coding concept.
