Our Coding Club

What is Coding Club?

Like the name suggests, it's a Karamu High school club that focuses on the development and teachings of different digital skills, for example students can currently pick from two different coding types which are learning coding languages like python and html, or learning how to code a robot. Students than use these skills to participate in upcoming events from Coding Club to have a chance at winning prizes.

What do you learn from Coding Club?

Coding Club teaches different year groups different skills, for example juniors would learn coding languages such as block coding which involves coding on basic websites like Scratch and Code.org. While seniors would learn text based coding which is a more complex coding language compared to block and is used on apps like Javascript and Python, this is important because we are teaching both groups important skills to prepare them for future school internals and upcoming competitions involving the Karamu Coding Club. Coding Club also develops skills around teamwork, creativity, and technical skills.

Who can help you in Coding Club

If you struggle to learn in the Coding Club, we have staff members and senior students who all have experience with basic and advanced coding languages and who are all happy to help others in need.

How often is Coding Club held

Coding Club is currently being held on Wednesday first break and Thursday first break, however these times can change and it is best to check the Coding Club teams page incase the times change or you can message the main teacher (Mrs Rodrigo) to find out actual times Coding Club is held.
